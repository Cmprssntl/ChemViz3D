# 更新日志

## 1.0.1 - 2026-08-17

### 新增

- 增加统一的 AI 解析入口：先匹配本地 JSON 预设，未命中后调用 OpenAI Chat Completions 兼容服务。
- 增加 `chemvz: 2` 严格校验、Markdown JSON 清理、网络/格式失败自动重试和最终错误报告。
- 增加 21 组常见分子本地预设，支持一个预设文件配置多个精确别名。
- 增加文本模型和图像理解模型的独立配置、独立系统提示词和重试次数设置。
- 增加 `settings.int` 配置模板及被忽略的 `settings.developer.int` 开发者覆盖配置。
- 增加 AI 设置界面：首次空配置启动提示、API 请求地址完整 endpoint 预览、保存文件和浏览器缓存，以及后续修改入口。
- 增加系统提示词修改确认警告，默认提示词按文本/图像模型分别提供。
- 增加界面语言、原子标签和显示模式的浏览器缓存。
- 增加 Vite 开发环境同源 AI 代理，改善 Linux 开发时上游 CORS 预检失败的情况。

### 修复与改进

- 完成 Linux 依赖安装、TypeScript/Vite 构建和开发服务器验证，补充跨平台启动说明。
- 延续并整合 `v1.0.0` 的 UFF 几何优化、VSEPR 建模、共面检测、构象搜索、测量和分子属性功能。
- 修正配置优先级：开发者配置仅在开发服务器使用，生产构建不会注入开发密钥。
- 改进 AI 网络错误信息，包含目标地址和 CORS 排查提示。

## 1.0.0 - 2026-07-15

- 首个预发布版本。
- 加入 UFF 力场几何松弛及一系列分子结构、共面性、构象搜索和 3D 交互改进。

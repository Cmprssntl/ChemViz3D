=================================
使用说明
ChemViz3D 是一个面向化学学习的程序。从正式版开始，它不再依赖浏览器：启动后会打开原生桌面窗口。

一、选择安装方式
----------------

Debian/Ubuntu 安装包：

```bash
sudo apt install ./*.deb
chemviz3d
```

Debian/Ubuntu 便携版：解压附件中相应压缩包，进入解压目录并运行：

```bash
./ChemViz3D
```


二、首次启动和 AI 设置
----------------------

程序启动后即可使用本地分子预设。输入化学式、常用名称或结构描述，点击“可视化”。

需要 AI 解析时，在左侧设置中填写文本模型的 API Key、模型名和 OpenAI 格式兼容的请求地址（通常填写到 `/v1`）。空值或无效配置会在请求前被拦截，并自动打开 AI 设置。
图像模型是为未来可能的新功能预留的，目前无效。

三、工作目录文件
----------------

- 便携版运行目录中的 `settings.int`、`molecules/` 和 `screenshots/`：便携版的全部可变数据。
- 安装版 `~/.config/ChemViz3D/settings.int`、`molecules/` 和 `screenshots/`：安装版的全部可变数据。
- `molecules/presets/`：本地分子预设；安装版首次启动时从程序包解压到上述配置目录，后续新增文件会自动读入。你可以下载附件中的预设扩展包并解压到上述目录中，以增加预设数目。这可能可以改善没有能力使用AI解析的情况下的使用体验。
- `screenshots/`：截图保存于此。
- `molecules/cache/`：AI解析缓存
- `settings.int`：配置文件，以json格式保存。开发者不建议手动修改配置。


便携版和安装版使用不同的数据目录，互不干扰。便携版请保持程序目录可写。

程序会优先写入当前工作目录。若目录只读，则回退到当前用户的配置目录。请从可写目录启动便携版，以便设置和缓存随包保存。

四、常用操作
------------

- 鼠标拖动旋转，滚轮缩放，点击原子或化学键查看属性。
- 左侧工具可切换球棍/空间填充显示、右侧测量、构象搜索。
- 顶部按钮截图；复位按钮恢复视角； X 清空当前渲染区。
- 快捷键：`R` 复位视角，`Ctrl+S`（macOS 为 `Cmd+S`）截图。

五、运行环境
------------

发行包已包含 Python、PySide6、Qt WebEngine 和前端运行所需文件。Debian/Ubuntu 若启动时报 Qt xcb 依赖缺失，请执行：

```bash
sudo apt install libxcb-cursor0
```

Windows 和 macOS稍后提供。

使用说明
ChemViz3D 是一个面向化学学习的程序。这是安卓版，特别进行触控适配。

一、选择安装方式
----------------
下载附件中的apk包，走常规流程安装即可。

二、首次启动和 AI 设置
----------------------

程序启动后即可使用本地分子预设。输入化学式、常用名称或结构描述，点击“可视化”。

需要 AI 解析时，在左侧设置中填写文本模型的 API Key、模型名和 OpenAI 格式兼容的请求地址（通常填写到 `/v1`）。空值或无效配置会在请求前被拦截，并自动打开 AI 设置。
图像模型是图像解析特别需要，如果你需要使用图像解析功能，请填写，并确保模型支持图像理解功能。

四、常用操作
------------

- 单指拖动：旋转；双指捏合：缩放；双指拖动：平移。。
- 左侧工具可切换球棍/空间填充显示、右侧测量、构象搜索。
- 顶部按钮截图（保存到相册）；复位按钮恢复视角； X 清空当前渲染区。
